# Físico dos Deuses

App pessoal (PWA) da campanha de 180 dias: quests no estilo Solo Leveling, scan 3D, treino adaptativo, nutrição, diário e o "Sistema", um coach com voz.

- Funciona no iPhone (Safari → Compartilhar → Adicionar à Tela de Início) e no PC.
- Os dados ficam no próprio aparelho (localStorage + IndexedDB). Sincronização opcional por Gist secreto.
- O cérebro do Sistema usa a chave gratuita do Google AI Studio, configurada no app (nunca fica no repositório).
- Voz neural offline em português (Piper, voz Faber) com efeito de rádio, ou voz do iPhone.
- Notificações gratuitas pelo app ntfy, enviadas por um workflow agendado do GitHub Actions.

Nada pessoal (fotos, medidas, chaves) fica neste repositório.
